# 项目背景与目标（sediment）

> 一句话：**在部署的任务流上，用 belief 残差给每一次经验定价，只把值得留的蒸进参数——让 agent 越用越强。**

## 1. 第一性原理

本项目的出发点是三段递进的判断：

1. **Harness / 上下文侧的"自进化"只在 edge case 上涨分，不提升能力。**
   自证：robagent 实验中，code-centric harness 优化在机制层（mechanism-layer）可迁移（GAIA +50%），
   在解释层（interpretation-layer）过拟合回退（tau2-banking 测试集低于 v0）。
   他证：CL-Bench（arXiv 2606.05661）发现朴素长上下文 ICL 直接打赢 ACE/Mem0 等专门记忆系统
   （ACE gain 仅 8.6% 且成本最高）；SEAGym（2606.17546）发现频繁的 harness 更新不提升 held-out，
   中途有用的快照后期崩坏。上下文能存"可检索的程序与事实"，但改不了策略先验。

2. **因此需要进入参数与梯度。** 但必须警惕：天真地进梯度只是把 edge-case patch
   从可读的 context 搬进不可读的权重——解释层残差写进参数照样过拟合，而且全局生效、
   不可审计、难回滚（行为学证据：arXiv 2607.00368 证明一步 LoRA 降 loss 但自由回忆为零，
   **loss 下降 ≠ 行为改变 ≠ 能力**）。真正的分界不是 context vs 参数，
   而是**写入的残差是否在可迁移的机制层**。

3. **部署过程中的数据量不足以做一次 large RL 训练。** 所以学习必须发生在与环境交互的
   过程中——流式处理任务的同时更新参数（TTT），目标是**越用越强**。
   对"数据不够"的正解不是攒更多数据，而是提高每次交互提取的监督比特数：
   scalar reward 每条轨迹 1 bit；hindsight belief 残差给每个 observation token
   一个带符号的 delta（P0 实测：in-context 经验增益 +0.096，w_t 峰值定位在 error message）。

## 2. 理论骨架：后验蒸回先验

学习 = 把证据条件化的后验蒸回先验。π(·|x, E_x) 是拿到经验 E_x 后的逐任务后验；
离线 RL 把成千上万个任务的后验平均掉再蒸回（残差压成标量 reward 是退化情形）；
TTT 是这个式子的原生形态：逐任务地 x → E_x → Δθ。三个可计算投影
（GRPO / 策略残差 / 信念残差）不是三条路线，而是同一循环的三个部件：
**残差产生信号（交互）→ 门控定价（本项目的贡献）→ 蒸馏固化（OPD 是算子）**。

**证据完备性（reward-optional，而非 reward-free）**：reward 不是与环境反馈并列的另一类信号，
而是证据流的一个**高可信、低带宽子通道**——outcome 标签和 error message 一样，都是进入 E_x 的
环境发射物，被同一套 hindsight 打分定价。严格版本：当证据退化到只剩 optimality 标量时
（控制即推断的 O 变量，p(O=1|τ) ∝ exp(r)），"把证据后验蒸回先验"退化为 reward-weighted /
advantage-weighted regression（RWR/AWR 族）——**RL 是本框架可推导的特例**，不只是修辞。
因此方法对 reward 的态度是：有则作为高精度证据消费（信任分级上可降低门控的重复性要求），
无则由反馈文本承担全部证据——同一套机器，不同的精度参数。

术语纪律：本方法的安全性来自**外部证据接地**，不是"自洽"——自洽恰是 TTRL 系的失败模式
（多数投票完全自洽却坍缩，Co-rewarding 称之"自洽幻觉"）。论文中不用 self-consistent
描述本方法，用 evidence-grounded。

关键补充：**残差是相对当前信念的**。θ_t 觉得惊讶的事 θ_0 不觉得——信号的定价本身是
on-policy 的。这是 online 流式不可被离线批处理替代的深层原因（不只数据要新鲜，定价也要新鲜）。

## 3. 领域断裂点（2026-08 文献态势）

参数化 TTT 的全部主流工作收敛于同一个保守配方：**LoRA/窄参数 + 少步 + 逐实例重置**。
重置不是偷懒，是因为跨实例累积目前必崩：

- 累积式上下文蒸馏互相覆盖，SQuAD EM 归零（arXiv 2605.28889）；
- SEAL 自报连续 self-edit 灾难性遗忘（2506.10943）；
- 纯自奖励持续训练必然 reward hacking 坍缩（SRT, 2505.21444）；
- TTRL 存在"正确答案灭绝窗口"（TTRL-Guard, 2605.19444）；
- agent 侧最新的 aTTT（2607.03441）只敢在单 episode 内累积、结束即重置。

而"越用越强"按定义必须跨任务累积。**从"重置"走到"安全累积"，缺的是一个决定
什么值得固化的价值定价栈——这正是本项目的位置。** 它的新颖核心在最细粒度：
**逐 token 的后验残差定价（w_t = relu(δ)）同时决定写入的方向与安全**（2026-08-23
实测：同剂量下无定价写入崩、定价写入立——定价不只是效果问题，是安全问题）；
其上的任务级台账（G1）与更新级验证（G2/G3）是粗粒度保险层，EMA 阻尼合并是
标准护栏（短流实测可独立吸收单颗毒更新；验证门的增量价值在长流/强剂量下检验）。

## 4. 定位（四轴对比）

| | Agentic RL 后训练 | aTTT (2607.03441) | TT-SI (2510.07841) | sediment（本项目） |
|---|---|---|---|---|
| 协议 | 离线批量、多 epoch、相位分离 | episode 内 transductive | 逐实例、用完重置 | 流式 predict-then-update、single-pass |
| 累积性 | 冻结 checkpoint | episode 末重置 | 重置 | **跨任务持久累积（唯一）** |
| 信号 | reward 标量 | 自 NTP（无对比无评价） | 自生成样本 | hindsight belief 残差（稠密、带符号、免 reward） |
| 每任务采样 | 大批量 rollout | 1（episode 内切片） | 1 | **1**（重试仅由门控触发） |
| 回答的问题 | 怎么炼更强的通用模型 | 这题做到一半别忘了在干嘛 | 这题怎么临时抱佛脚 | **做完这题，哪些经验值得永久写入，让下一题受益** |

两句定位话术：
- **aTTT 止步于 episode 结束时的那次 reset；我们从 reset 点开始——决定哪些东西不该被 reset。**
- **TTRL 需要 64 条 rollout 做多数投票（这正是它不可部署的原因）；我们的 hindsight 信号
  不依赖任何组内统计，是第一个能在 G=1 部署条件下运行的参数化流式方法。**

## 5. 方法要点（部署真实性约束下的设计）

- **G=1 主协议**：每任务只作答一次，这次作答就是评测（predict-then-update）。
  信号构造所需的"对比组"来自**流的历史**：experience buffer 检索 K 条相似任务轨迹
  + 本任务自身的结果摘要（hindsight 构块的 copy-safe 设计沿用 resid）。
  组内方差的降噪由**时间维度**补偿：同类惊讶在流中重复出现才固化（不对称铁律：
  默认遗忘，留存靠挣）。
- **定价即门控（2026-08-25 定型）**：主贡献是后验残差定价的蒸馏，逐 token 的带符号
  δ 死区是最细粒度的门（决定写入方向与安全）。三条实测安全约束进入定价本身：
  ①只训动作通道（观测 CE 背实例数据是毒源）；②剂量∝证据（Σw 低于下限不满剂量）；
  ③负信用只落值/内容/工具名，不落框架 token。
- **门控三级 = 保险层**：G1 幅度门 + 重复性台账 → G2 行为门（重放状态上改变 action）
  → G3 迁移门（探针）。实测挡崩不生增益、探针噪声≈信号，主臂只量测不执行，长流待验。
- **写入梯子**：任务内草稿（可选 aTTT 式 Tier 0，episode 末即弃）→ session LoRA
  （流式快适配器）→ 门控通过后合并固化。防护件：KL-to-base 信任域、少数派保护、
  NCA 锚定（防"内化后上下文回归反而掉分"，2606.11627）、读侧熵门控（2605.28889）。
- **失败重试 = 门控触发的 deliberate practice**：失败且高惊讶的任务带经验块重试一次
  （重试是真实使用行为），同时服务用户、构造对比、丰富 buffer。

## 6. 科学主张（每条对应一张主图）

- **C1（信号）**：belief 残差可定位可迁移的经验信息（P0：+0.096 增益，w_t 峰值在 error message）。
- **C2（内化）**：w_t 加权蒸馏能把 in-context 增益写进权重，等算力下 ≥ ICL，
  且优于无加权蒸馏与 aTTT 式自 NTP。
- **C3（负对照）**：无门控的跨任务累积先涨后崩，毒源可归因（预期主要是解释层写入）。
- **C4（主结果）**：残差定价门控使累积从负转正——流式曲线斜率为正（W-AUC）、
  冻结快照在 held-out ID/OOD 上提升、无灾难遗忘。

## 7. 适用域（诚实边界）

本方法 **reward-optional**：有 reward 时作为高精度证据消费（门控信任分级随之放宽），
无 reward 时由反馈文本承担全部证据——同一套机器。实用动机仍然成立：真实部署的常态是
**reward 缺失或不可信、分布非平稳、需要流内即时复利**。
若 reward 齐备、分布平稳、可以等待离线批训练，离线 RL 是正确工具，不与之竞争——
且在那个极限下本框架的退化形式就是它（见第 2 节 RWR 归约）。
剥掉门控和 belief 残差，剩下的确实退化为小 batch online RL/SFT——
所以流式不是贡献，**稠密残差定价 + 门控固化才是**。

## 8. 评测纪律

- 流式指标：W-AUC（学习曲线下面积，Meta-TTL）、gain = 有状态 − 无状态（CL-Bench）。
- 泛化证明：定期冻结快照测 held-out ID/OOD（SEAGym 协议）+ 换皮任务控制 + 通用回归套件。
- 一切对比 compute-matched（报 rollout 数、梯度 FLOPs、相对开销倍数）。
- 主图 ≥3 种子 × 3 流序。Judge/门控评估与 actor 用不同模型（judge isolation）。
