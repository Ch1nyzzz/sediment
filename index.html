00背景：为什么必须绕开 reward

我们想做的是部署中持续变强：agent 在真实任务流上一边干活一边学。但日常使用场景有两个硬约束，直接排除了标准的 RL 路线。

  • 数据量不够。部署流里一天几百条交互，不是 large-scale RL 那个量级，训不出策略。
  • reward 不清晰。没有干净的打分函数，也不可能让人逐条标注；成败常常只有一个模糊的、事后的环境信号。

所以 test-time continual learning 的信号只能从两处来：agent 自己积累的经验（memory） 和 环境反馈。这条线就是顺着这个约束一步步走下来的——每一步都是上一步结论逼出来的。

STEP 1

memory 到底怎么用才有效？

先不谈训练。把记忆放进上下文，测出哪种形态真的能提升成绩——找不到有效的形态，后面无从谈起。

STEP 2

那这个提升本身就是学习信号

同一份权重，读记忆 vs 不读记忆，行为差异就是「记忆教会了什么」。它不需要任何 reward 标注。

STEP 3

把这个差异蒸馏进参数

用 reverse KL 在线写进 LoRA，让模型在不带记忆时也具备同样的行为。

01第一步的结论：一条完整的成功轨迹，胜过任何形式的多条

512 题固定池，单次 rollout，不做任何训练——纯粹比较记忆的形态。

把记忆放进上下文，成绩怎么变

蓝色是最好的形态；虚线是完全不给记忆的基线。

最好的形态是「生成之前先筛，只注入一条」：用环境已经给过的成败标签先把失败的经验过滤掉，再按任务相似度取一条完整的、可执行的成功轨迹，原样放进首条消息。这比不给记忆多出 15 题。

而把多条记忆拼在一起，一律更差，甚至差过完全不给记忆。并列 4 条成功反思、把它们压缩成 lesson、扩到 8 条覆盖更多来源——三种做法全部低于基线。不是因为太长被截断（内容都完整注入，远没到上下文上限），而是多条跨环境的经验互相冲突，模型拿到的是彼此矛盾的行动先验。

这一步的可迁移结论：记忆的价值来自筛选，不是来自数量。该在生成前用已知信号选出一条可信的，而不是把检索到的都塞给模型。

02第二步的结论：这个提升可以直接当学习信号，不需要 reward

既然「带一条记忆」能稳定提升成绩，那么同一份权重、读记忆与不读记忆之间的行为差异，本身就编码了这条记忆教会了什么。把它当作训练目标，全程不需要任何人工 reward。

学习信号是怎么构造的

教师和学生是同一个模型的同一份权重，唯一区别是教师多读了一条记忆；教师只是在学生自己写出来的轨迹上重新打一次分，不需要第二次 rollout。

为什么是 reverse KL。部署时模型跑的是 prompt-only，所以期望必须在学生自己的状态分布上取。反过来做（在教师生成的轨迹上算 forward KL）实测只有 0.008 nats——在教师自己写的轨迹上，它说的话学生本来就会说，几乎没有信号。

为什么不是「挑出好 token 做 SFT」。早期版本用阈值门选出「变好的 token」再做交叉熵。在同一批 token 上把两个目标各算一次：交叉熵均值 0.365，KL 均值 3.538——门选出来的正是模型已经会做的事，梯度接近零。那条贴着基线的平线不是学坏了，是根本没学。换成 KL 之后信号大了约十倍。

环境反馈用在哪。只用在检索侧：哪条历史经验算「成功」由环境自己给出，用来过滤 donor。训练目标里没有任何标量 reward，也不需要成败二值化。

04路上确认掉的几件事

这些都是负结果，但它们决定了方法长成现在这样。

试过什么结论
在关键时刻才注入记忆（模型要动手改数据时打断它，回灌一条相似的历史步骤） 显著有害。模型把示范当成「照做」而不是「参考」：要么放弃写操作改去查询，要么直接抄示范里的工具和参数。换措辞、换同族来源都救不回来。有用的是「注入什么」，不是「什么时候注入」。
通用的目标完成度追踪（维护一个任务清单，只有成功写操作才算完成） 显著有害。通用判定只能识别一半的完成情况，剩下的假「未完成」逼着模型反复重写，直接把任务打崩。这类机制要靠领域专用的判定器，我们拿不到。
不加约束地持续累积更新 先涨后崩。早期窗口领先，一次坏的合并之后模型进入「循环查询、永不结算」，后续任务全部撞满步数上限。短跑出来的漂亮曲线是崩溃前的截断。
让训练也吃观测 token 这是崩溃的主要毒源：模型把病人档案、日志 ID 这类实例数据背进了权重。策略和世界模型共用同一个模型时，观测侧的损失会泄漏进策略。现在只在动作 token 上学。
先把记忆编译成精炼的经验条目再用 没有净收益（压缩后的版本与原文并列打平，都低于单条完整轨迹）。当前方法因此不含任何 compiler，直接用原始轨迹。

另外一个有意思的观察：模型越强，越依赖同环境的具体经验。在 8B 上，跨环境的通用记忆增益消失，而同环境记忆成为唯一显著的正向（+24 题）。这意味着评测必须打乱环境顺序，否则「同环境内的快速适应」会伪装成「跨环境迁移」。
